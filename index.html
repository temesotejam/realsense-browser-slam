RGB + Depth persistent-map localization

Normal odometry now includes a zero-motion gate using 16×16 block-median Depth, RGB feature geometry, and ICP increment. If all three remain nearly unchanged for four consecutive frames, the state becomes STATIC and pose integration is frozen. Each map keyframe stores metric Depth plus RGB corner features and 128-bit local descriptors. Revisits are ranked by RGB appearance, checked for 2D geometric consistency, then verified by forward + reverse 3D Depth ICP. Large pose corrections require strong RGB geometry plus low Depth error. Recovery and medium/large loop closures must match the same keyframe twice before the pose is moved. Once tracking is LOST, odometry alone is not allowed to resume: a verified map match is required. When relocalization succeeds in BUILD mode, only the untrusted segment created since the last accepted map anchor is rigidly repaired back into the matched map frame. Earlier trusted keyframes are left untouched. If RGB is active, recovery never falls back to Depth-only because of a temporarily weak RGB frame. A verified revisit anchors the current 6DoF pose back to the stored map coordinates. Save Map preserves both Depth and RGB features.
